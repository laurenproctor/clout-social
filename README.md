# Clout — Trend Intelligence & Multi-Channel Social Studio

Clout helps brands and creators discover trending industry topics using real-time GDELT news signals and sentiment, turn those signals into platform-optimized hooks, and publish directly to social networks via Zernio.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Setup environment variables:
   Copy `.env.example` to `.env.local` and add your API keys:
   ```bash
   cp .env.example .env.local
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Launch with Claude Code CLI:
   ```bash
   claude
   ```
